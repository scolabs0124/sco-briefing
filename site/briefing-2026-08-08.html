2. 단순 평균 등급은 착시…수시 원서 접수 전 입결 데이터 제대로 봐야

아주경제 · 2026-08-08 · 원문
🎯 학부모 링크 👀 미리보기

수시 원서 접수 앞두고 입결 데이터 오독 주의. 단순 평균 등급은 착시, 70% 컷·환산 점수 확인 필수

📌 무엇이 바뀌었나
  • 평균 등급은 착시 유발: 대학 발표 '평균 등급'은 합격자 전체 평균. 실제 합격 가능 라인은 70% 컷 또는 최저 등급 확인 필수
  • 환산 점수 반드시 확인: 대학마다 학생부 반영 방법 다름. 단순 등급이 아닌 대학별 '환산 점수'로 비교해야 정확한 지원 가능
❓ "작년 평균 등급이 3.2등급이니까 우리 애 3.5등급이면 쓸 만하겠죠?"
→ 절대 안 됩니다. 평균은 합격자 전체 평균일 뿐, 실제 합격 가능 라인은 70% 컷(하위 30% 제외)입니다. 또한 대학별 환산 점수로 변환해야 정확한 비교 가능. 단순 등급 비교는 착시입니다
📱 학부모 카톡문

[SCO 수시 데이터 분석 특보] 수시 원서 접수 한 달 앞! "평균 등급만 보고 쓰면 실패합니다" 대학이 발표하는 '평균 등급'은 합격자 전체 평균일 뿐, 실제 합격 가능 라인은 '70% 컷' 또는 '최저 등급'입니다. 또한 대학마다 내신 반영 방법이 달라 단순 등급 비교는 착시를 유발합니다. ✅ 정확한 입결 분석법 1. 70% 컷 또는 최저 등급 확인 2. 대학별 환산 점수로 변환 3. 반영 과목·비율 정확히 적용 수시 6장, 데이터를 제대로 읽어야 성공합니다. 스코랩스가 정확하게 분석해드립니다.

📰 카드뉴스 제목
  • 평균 등급의 함정, 당신은 속고 있다
  • 70% 컷이 진짜 합격 라인이다
  • 환산 점수 계산법 완전 정복
💡 SCO 관점

입결 데이터는 '성적'이 아닌 '완성도' 관점으로 읽어야 함. 평균 등급은 합격자 전체 평균일 뿐, 실제 합격 가능성은 70% 컷·환산 점수로 판단. 데이터 정확히 읽는 능력이 수시 성공의 핵심. 스코랩스는 착시 없는 데이터 분석 지원
